Bayesian Hierarchical Model of LDL Cholesterol

December 2023 · Python · R · MCMC

Used Bayesian hierarchical modeling to study LDL cholesterol distributions across demographic groups.

Project overview

Using NHANES data, this project models LDL cholesterol distributions among sex and ethnicity groups with a Bayesian hierarchical model fitted using Markov chain Monte Carlo.
