Predicting Sepsis — STATS 503 Data Challenge

March–April 2023 · Python · Jupyter · AdaBoost · Cross-validation

Developed an AdaBoost classifier for sepsis prediction with missing-data imputation and hyperparameter tuning.

Project overview

This project predicts the likelihood of sepsis using quantitative and categorical predictors. The workflow includes missing-value imputation and cross-validation to select hyperparameters for an AdaBoost model.
